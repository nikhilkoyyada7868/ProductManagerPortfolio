# Nikhil Koyyada Portfolio

Personal Product Manager portfolio for Nikhil Koyyada, built with Vite, React, Tailwind CSS, and Framer Motion.

## Highlights

- Product Manager positioning with resume download
- Project filters and case-study style project cards
- Animated timeline
- Skill radar
- Contact form that opens an email draft
- Responsive layout for desktop and mobile

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- React Icons

## Local Setup

```sh
npm install
npm run dev
```

The local development URL is usually `http://localhost:5173/`. If that port is busy, Vite will show the next available port in the terminal.

## Build

```sh
npm run build
```

The production output is generated in `dist`.

## Deployment

This app is ready to deploy on Vercel with:

- Framework preset: `Vite`
- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`
